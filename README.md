# Hello World Website

A minimal Node.js + Express "Hello World" website, ready to deploy on Vercel.

## Features
- `/` renders a beautiful Hello World page
- `/api/hello` returns JSON

## Local Development
```bash
npm install
npm start
# open http://localhost:3000
```

## Deploy
Push to GitHub and import into Vercel, or run:
```bash
npx vercel
```
